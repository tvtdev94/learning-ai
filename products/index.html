agentkit

Bộ skill Claude Code của tôi, cài một lầnMy Claude Code skills in one plugin

Gom các skill tôi viết cho Claude Code vào một plugin tên tvt: viết lại văn cho tự nhiên, mài prompt, hiểu video và dựng phim tin tức bằng code.

The Claude Code skills I write, shipped as one plugin named tvt: natural rewriting, sharper prompts, video understanding and code-built news films.

  • humanize-writing: viết lại hoặc soi văn có giọng AI, tiếng Việt và tiếng Anh, không đổi dữ kiện.humanize-writing: rewrites or audits AI-sounding Vietnamese and English prose without changing facts.
  • refine-prompt: biến prompt thô thành prompt rõ ràng, dán dùng ngay, kèm bảng thay đổi.refine-prompt: turns rough prompts into sharp, paste-ready ones with a change table.
  • cc-video: hiểu video theo từng cảnh: keyframe, transcript, OCR và chú thích thành timeline Markdown.cc-video: shot-aware video understanding: keyframes, transcript, OCR and captions as a Markdown timeline.
  • news-film: biến bài báo thành phim tin tức kiểu truyền hình bằng code, có bản 16:9, Reels và Shorts.news-film: turns a news article into a TV-news-style film made in code, in 16:9, Reels and Shorts cuts.

dbread

Proxy cơ sở dữ liệu chỉ-đọc cho AIRead-only database proxy for AI

Đứng giữa AI và cơ sở dữ liệu của bạn: cho Claude Code truy vấn đọc trên nhiều loại DB, còn mọi lệnh ghi bị chặn qua 5 lớp kiểm tra độc lập.

Sits between your AI and your databases: Claude Code gets read queries across many databases, while writes are blocked by five independent layers.

  • SQL chỉ chạy SELECT, WITH, EXPLAIN, SHOW; MongoDB chỉ find, count, distinct, aggregate.SQL runs only SELECT, WITH, EXPLAIN and SHOW; MongoDB only find, count, distinct and aggregate.
  • Thêm kết nối bằng một lệnh, không phải sửa YAML tay.Add a connection with one command, no hand-edited YAML.
  • Kèm skill hướng dẫn Claude quy trình truy vấn an toàn.Ships a skill that teaches Claude the safe query workflow.

Lưu ý từ tài liệu dự án: chỉ tài khoản DB chỉ-đọc mới là bảo đảm không thể vượt qua; các lớp còn lại giúp giảm rủi ro.

From the project docs: a read-only database user is the only guarantee that cannot be bypassed; the other layers reduce risk.
