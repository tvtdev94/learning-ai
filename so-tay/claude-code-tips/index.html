CLAUDE.md global: luật chung cho mọi dự ánGlobal CLAUDE.md: one set of rules for every project

Claude Code đọc file ~/.claude/CLAUDE.md ở đầu mọi phiên, trong mọi dự án trên máy bạn. Tài liệu gọi nó là "User instructions": sở thích cá nhân áp cho tất cả dự án.[1] Viết cách bạn muốn làm việc vào đây một lần, khỏi phải dặn lại mỗi phiên.

Claude Code reads ~/.claude/CLAUDE.md at the start of every session, in every project on your machine. The docs call it "User instructions": personal preferences for all projects.[1] Write down how you want to work once instead of repeating it every session.

Dòng đầu file của tôi nói rõ vì sao nó tồn tại:The first line of my file says why it exists:
Why: guessed facts and long answers cost me time. These rules fix both.

File của tôi có 6 nhóm luậtMy file has six groups of rules

  • FactsKhông nói về hệ thống đang chạy theo trí nhớ. Mỗi dữ kiện kèm nguồn: file:dòng, lệnh và kết quả. Chưa kiểm thì ghi "not verified".No claims about a live system from memory. Every fact cites its source: file:line, or a command and its output. Unchecked means "not verified".
  • Before you buildVới lĩnh vực lạ hay thuật toán khó, xem 1–2 dự án mã nguồn mở tốt trước. Mượn ý tưởng, không chép code.For an unfamiliar domain or a hard algorithm, look at one or two good open-source projects first. Borrow ideas, not code.
  • SolutionsKhông cãi. Sửa tận gốc, không vá tạm. Chỉ nói "xong" sau khi đã chạy kiểm tra và đưa kết quả.Don't argue. Fix the root cause, no temporary patches. Say "done" only after running the check and showing its output.
  • Decisions I must makeKhi cần tôi quyết, hỏi một agent cố vấn trước, rồi mới hỏi tôi kèm khuyến nghị và đánh đổi của từng lựa chọn.When I must decide, ask an advisor agent first, then ask me with its recommendation and a trade-off for each option.
  • TestsViết hay sửa test thì nạp skill kiểm tra test trước. Đổi tên, sửa chữ, tài liệu thường không cần test mới.Load a test-review skill before writing or changing tests. Renames, copy and docs usually need no new test.
  • Browser and background tasksHỏi tôi dùng trình duyệt nào trước khi mở. Việc chạy nền lâu thì theo dõi có hạn giờ và báo lỗi ngay.Ask which browser to use before opening one. Watch long background jobs with a timeout and report failures right away.

Lưu ý từ tài liệu chính thứcNotes from the official docs

  • Ngắn và cụ thểShort and specificLuật càng cụ thể, càng ngắn thì Claude làm theo càng đều. Nên giữ mỗi file dưới 200 dòng; file dài tốn context và bị làm theo kém hơn.The more specific and concise the rules, the more consistently Claude follows them. Aim for under 200 lines per file; longer files cost context and lower adherence.[1]
  • Là context, không phải khoáContext, not a lockClaude coi CLAUDE.md là ngữ cảnh, không phải cấu hình bắt buộc. Muốn chặn hẳn một hành động thì dùng hook PreToolUse.Claude treats CLAUDE.md as context, not enforced configuration. To block an action outright, use a PreToolUse hook.[1]
